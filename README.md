# Serpientes y Escaleras con números mayas

Juego para dos personas desarrollado con HTML, CSS y JavaScript, sin dependencias.

## Archivos

- index.html: página principal.
- styles.css: diseño.
- game.js: numeración maya y reglas del juego.

Mantén los tres archivos juntos en la raíz del repositorio. Abre index.html para jugar localmente. No se necesita instalación ni compilación.

La versión independiente entregada por separado como index.html contiene también los estilos y el JavaScript: puedes utilizarla sola en lugar de estos tres archivos.
